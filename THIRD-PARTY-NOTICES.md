# Third-party notices

Herta's installers ship the app as bundled JavaScript: every library below
is compiled into the main-process or renderer bundle and redistributed
inside the binary under its own license, reproduced here in full. This file
is GENERATED from the bundle itself (`packages/gui/scripts/third-party-notices.mjs`,
reading the module manifest `electron.vite.config.ts` writes at build time),
so it lists exactly what ships — not what is declared — and a release build
fails if it goes stale.

Not listed here, because they travel separately:

- **Electron, Chromium and Node.js** — electron-builder places
  `LICENSE.electron.txt` and `LICENSES.chromium.html` next to the executable.
- **Herta's own code** — MIT, see `LICENSE`.
- **The character, artwork and voice** — not software; see the scope note at
  the top of `LICENSE` (Herta is a character from Honkai: Star Rail, ©
  HoYoverse; this is an unofficial fan project).
